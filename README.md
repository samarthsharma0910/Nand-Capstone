## Part B — Python Hack assembler
- `capstone/assembler.py` implements source cleaning, a two-pass symbol/code translation pipeline, predefined symbols, variable allocation, and — for K mod 3 = 1 — clear `Line n: ...` error messages for invalid lines instead of crashing.
- Run the built-in tests:

```powershell
python .\assembler.py --self-test
```

- Assemble a program:

```powershell
python .\assembler.py Add.asm
```

The assembler output was compared with the official Nand2Tetris assembler output for `Add.asm`, `Max.asm`, `Rect.asm` and `Pong.asm`. Evidence is in `capstone/ScreenShots/PART-B/`.

## Part C — Box program (K = 79)
For roll number `2501730279`, K is `79`. The program draws a 64-pixel-wide (16 × ((79 mod 4) + 1) = 16 × 4), 20-row-high rectangle beginning at screen row 79 (rows 79–98) while a key is held, and clears it after the key is released. First word address = SCREEN + 32 × 79 = 18912.

- `capstone/Box.asm` — Hack assembly source.
- `capstone/Box.hack` — 43-instruction machine-code output generated by the Python assembler.

Generate the machine code again with:

```powershell
python .\assembler.py Box.asm
```

Run it in the Nand2Tetris **CPU Emulator**. Part A's chips are validated separately with their official Hardware Simulator tests; Part C is not run on the integrated `Computer.hdl` chip.
